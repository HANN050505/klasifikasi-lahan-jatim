Digitasi Ulang & Klasifikasi Tutupan Lahan Jawa Timur (Sentinel-2A)¶

Pengganti UTS. Alur: Business Understanding → Data Understanding → Modelling → Evaluasi → Peta web (Folium) → Deploy web statis.

1. Business Understanding¶

Tujuan: memetakan permukaan bumi Jawa Timur dari citra satelit Sentinel-2A ke dalam 5 kelas tutupan lahan (land use & land cover classification): bangunan (built-up), lahan pertanian/sawah (farm land), hutan (forest), hutan mangrove, dan perairan (water body: laut, danau/ranu).

Manfaat: pemantauan lahan pertanian (ketahanan pangan), alih fungsi lahan/tata ruang, konservasi hutan dan mangrove, serta pengelolaan sumber daya air.

Acuan klasifikasi di Indonesia: SNI 7645:2010 (klasifikasi penutup lahan) dan klasifikasi penutup lahan KLHK, yang membedakan hutan lahan kering, hutan mangrove, pertanian, permukiman, dan badan air, bukan hanya sawah vs non-sawah.

Keluaran: model klasifikasi dengan akurasi terbaik + peta web interaktif (Folium) berbasis satelit, dengan layer yang bisa difilter per kelas.

def random_points(geom, n, max_try=20000):
    minx, miny, maxx, maxy = geom.bounds
    out, t = [], 0
    while len(out) < n and t < max_try:
        t += 1
        p = Point(rng.uniform(minx, maxx), rng.uniform(miny, maxy))
        if geom.contains(p): out.append(p)
    return out
